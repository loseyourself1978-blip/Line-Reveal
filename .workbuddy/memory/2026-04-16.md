## v1.3.1 Bug 修复

### Bug#A: 命数消耗不规律（P0）
- 根因：碰撞链导致多条命一次性清零
- 修复：cancelDrawInProgress 防重入标志
- 文件：engine.ts

### Bug#B: 失败界面文案（P0）
- 根因：文案为 "FAILED"，用户期待 "YOU LOSE"
- 修复：改为 YOU LOSE，z-[100] 层级
- 文件：ResultScreen.tsx

### Bug#C: 小范围划线解锁（P1）
- 根因：MIN_UNLOCK_RATIO=0.05 太高，percent 计算方式不准确
- 修复：MIN_UNLOCK_RATIO=0.03，percent 改用 trashArea
- 文件：engine.ts

### Bug#D: LivesDisplay 不显示（P1）
- 根因：GameCanvas/LivesDisplay 层叠顺序问题
- 修复：GameCanvas absolute+z-0，LivesDisplay z-50+absolute
- 文件：GameCanvas.tsx，LivesDisplay.tsx

### Bug#E: Capacitor Sync 失败（P1）
- 根因：cap sync 不会复制 JS bundle 到正确位置
- 修复：使用 cap copy ios，并手动验证文件
- 构建流程：npm run build → npx cap copy ios → xcodebuild

## 重要教训

1. Capacitor sync 有时会失败，JS bundle 需要手动 cp 验证
2. LivesDisplay 必须设置 z-index+position 才能覆盖 Canvas
3. iOS 模拟器中 SVG 渲染为灰色但功能正常（颜色偏差不影响）
4. 模拟器窗口位置可能变化，每次测试前需要重新检测

## iOS 构建命令
```bash
cd ios/App && xcodebuild -project App.xcodeproj -scheme "Line Reveal" -configuration Debug -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build
```

## 完整构建流程
```bash
npm run build && npx cap copy ios && cd ios/App && xcodebuild -project App.xcodeproj -scheme "Line Reveal" -configuration Debug -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build
```
