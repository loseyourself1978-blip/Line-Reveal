# App Store 审核材料准备清单

**创建时间**: 2026-04-22  
**版本**: v1.5.0（更新于 2026-04-26）

---

## 一、必需材料

### 1. App Icon
- [x] 1024x1024 PNG（已生成）
- [x] iOS App Icon set（已更新）
- **位置**: `ios/App/App/Assets.xcassets/AppIcon.appiconset/`

### 2. 截图
需要准备以下尺寸的截图：

| 设备 | 尺寸 | 数量 |
|------|------|------|
| iPhone 6.5" (max) | 1284x2778 | 至少 1 张 |
| iPhone 5.5" (普通) | 1242x2208 | 至少 1 张 |
| iPad Pro 12.9" (2nd) | 2048x2732 | 至少 1 张 |

**建议截图**:
1. 欢迎界面（展示4种模式）
2. 游戏进行中（划线/弹球）
3. 胜利界面
4. 拼图模式
5. 消除模式
6. 画廊收藏

### 3. 应用描述
- **标题**: Line Reveal
- **副标题**: 划线解锁艺术
- **描述**（中文）:
```
《划线解锁神图》是一款独特的益智解谜游戏。

游戏特色：
- 4种游戏模式：经典划线、弹球解锁、拼图还原、宝石消除
- 弹球解锁：街机感玩法，打破砖块揭示艺术图片
- 30+关卡精心设计，闯关解锁艺术收藏
- 精美的艺术图片画廊
- 流畅的触觉反馈

适合喜欢解谜和艺术欣赏的玩家。
```

### 4. 关键词
```
解谜,益智,划线,艺术,图片,精灵,拼图,消除,游戏
```

### 5. 隐私政策 URL
需要创建或托管一个隐私政策页面。最低要求：
```
本应用不收集任何个人信息。
本应用不包含任何广告。
本应用不使用追踪功能。
如有任何问题，请联系：loseyourself1978@gmail.com
```

### 6. 年龄评级
- **选择**: 4+（所有年龄段）或 9+（轻微暴力）
- 由于涉及精灵碰撞，建议选择 **9+**

## 二、账号准备

### 1. Apple Developer 账号
- [ ] 注册 Apple Developer Program ($99/年)
- **链接**: https://developer.apple.com/programs/

### 2. App Store Connect
- [ ] 登录 App Store Connect
- **链接**: https://appstoreconnect.apple.com/

---

## 三、提交步骤

1. 登录 App Store Connect
2. 创建新 App
3. 填写应用信息
4. 上传截图
5. 选择年龄评级
6. 添加隐私政策 URL
7. 选择定价和可用性
8. 提交审核

---

## 四、审核时间
- 通常 24-48 小时
- 首次提交可能需要更长时间

---

## 五、常见拒绝原因及预防

| 原因 | 预防措施 |
|------|----------|
| 截图不符合要求 | 使用规定尺寸，提供实际截图 |
| 应用描述不清晰 | 使用本地语言描述 |
| 年龄评级过高 | 选择适合的分级 |
| 隐私政策缺失 | 添加有效的隐私政策 URL |
| 崩溃或无响应 | 测试所有设备 |
