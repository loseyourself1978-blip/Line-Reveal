Bug #A | P0 关键
命数消耗不规律
已修复
症状：碰撞后命数有时不减1，或者多条命一次性清零（5→0）
根因：碰撞链导致 cancelDraw 连续重入
修复：添加 cancelDrawInProgress 防重入标志，checkCollisions 中检查该标志
文件：engine.ts
Bug #B | P0 关键
失败界面文案
已修复
症状：用户没看到 "You Lose" 界面
根因：ResultScreen 文案是 "FAILED"，且 z-index 层级不足
修复：改为 "YOU LOSE"，设置 z-[100] 层级
文件：ResultScreen.tsx
Bug #C | P1
小范围划线解锁
已修复
症状：用户反馈"还是不能划线解锁小范围"
根因：MIN_UNLOCK_RATIO=0.05（5%）太高，percent 计算方式不准确
修复：MIN_UNLOCK_RATIO=0.03（3%），percent 改用 trashArea 直接计算
文件：engine.ts
Bug #D | P1
LivesDisplay 不显示
已修复
症状：模拟器测试中右上角没有显示命心
根因：GameCanvas/LivesDisplay 层叠顺序问题
修复：GameCanvas absolute+z-0，LivesDisplay z-50+absolute
文件：GameCanvas.tsx，LivesDisplay.tsx
Bug #E | P1
Capacitor 构建流程
已修复
症状：cap sync 不会正确复制 JS bundle
修复：使用 cap copy ios，并手动验证文件存在
构建流程：npm run build → npx cap copy ios → xcodebuild
